# signal

A frameless, draggable minimal Now Playing / MPRIS audio strip widget for Omarchy. Queries active MPRIS media players via `playerctl`, follows the active Omarchy theme colors, Hyprland corner rounding, and system language live, and can be dragged anywhere on the desktop.

## Shortcuts

| Key | Action |
| --- | --- |
| `Space` | Play / Pause |
| `N` / `Right` | Next track |
| `P` / `Left` | Previous track |
| `?` | Toggle shortcuts |
| `Q` / `Esc` | Quit / close shortcuts |
| Drag | Move widget on desktop |

## Build & Install

```sh
./bin/build
./bin/test
./bin/install
```
