# tminus

A frameless, draggable mission countdown and Pomodoro timer widget for Omarchy. Follows the active Omarchy theme colors, Hyprland corner rounding, and system language live.

## Presets & Modes

- **Pomodoro**: `25:00` (`25M`)
- **Sprint**: `15:00` (`15M`)
- **Break**: `05:00` (`05M`)
- **Stopwatch**: Count-up timer (`STOPWATCH`)

## Shortcuts

| Key | Action |
| --- | --- |
| `Space` | Start / Pause |
| `R` | Reset |
| `P` | Cycle preset (`25M` / `15M` / `05M`) |
| `M` | Toggle stopwatch mode |
| `+` / `-` or `Up` / `Down` | Adjust minutes |
| `?` | Toggle shortcuts |
| `Q` / `Esc` | Quit (or close shortcuts) |
| Drag | Move widget on desktop |

## Build & Install

```sh
./bin/build
./bin/test
./bin/install
```
